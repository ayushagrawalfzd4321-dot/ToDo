# Todo List

A simple Todo List built with React and Tailwind CSS.

## Features

- Add new todos
- Edit todos
- Delete todos
- Mark todos as completed
- Todos are saved in localStorage
- Responsive UI

## Tech Stack

- React
- Tailwind CSS
- Vite
- JavaScript
- localStorage
